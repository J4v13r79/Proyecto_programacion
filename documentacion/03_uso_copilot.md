1. ¿Cómo utilizaste las especificaciones para solicitar código a Copilot?

Antes de comenzar a programar se hicieron las especificaciones para tener más claro qué debía hacer el programa y cómo se iba a dividir. Con eso se le fue pidiendo a Copilot que ayudara a desarrollar cada parte, empezando por la clase SolidoRevolucion, después la calculadora y al final el programa principal.

2. ¿Qué revisaste o modificaste del código generado?

Se revisó principalmente que las clases tuvieran los atributos y métodos que se habían definido anteriormente. También se revisó la manera en la que se utilizaban las funciones matemáticas con SymPy y como se realizaban los cálculos.

En algunas partes fue necesario hacer cambios, sobre todo en las validaciones, para que el programa pudiera comprobar los datos que se ingresaban y no solamente realizar el cálculo.

3. ¿Copilot generó alguna respuesta incorrecta o distinta de lo solicitado?

En algunas ocasiones el código que proponía Copilot no funcionaba exactamente como se esperaba, por lo que fue necesario revisar qué estaba haciendo y corregirlo. Esto ocurrió principalmente con algunas validaciones de las funciones y con la manera de comprobar los radios dentro del intervalo.

No todas las sugerencias se utilizaron tal cual, ya que algunas se tuvieron que adaptar a la estructura que se estaba manejando en el proyecto.

4. ¿Cómo comprobaste que el código generado funcionara correctamente?

Se fueron probando las clases conforme se iban desarrollando, utilizando primero el ejercicio original y después otros casos para comprobar que los resultados no dependieran únicamente de una función específica.

También se comprobó que el programa pudiera calcular los volúmenes, mostrar los resultados y guardar los ejercicios en el historial. Se tenía que comprobar que no solo funcionara con los datos normales, sino que también reaccionara correctamente cuando se ingresaban datos que no eran válidos.

5. ¿Qué ventajas y limitaciones observaste al utilizar Copilot?

Copilot ayudó a avanzar más rápido al momento de programar, ya que permitía obtener ejemplos de cómo estructurar las clases y los métodos. También fue útil cuando surgían dudas sobre cómo implementar ciertas partes del programa.

Aun así, no siempre se podía utilizar directamente lo que generaba, porque en ocasiones era necesario modificarlo o revisar si realmente funcionaba. Al final, usarlo facilitó el desarrollo, pero también fue necesario entender el código y probarlo para evitar errores.

6. ¿Por qué es importante revisar el código generado por inteligencia artificial?

Porque aunque la inteligencia artificial puede ayudar a escribir código, no significa que todo lo que genere esté correcto. Es necesario entender qué hace cada parte para poder corregir errores y realizar cambios cuando sea necesario.

Además, si no se comprende el código, sería difícil modificar el programa o explicar cómo funciona, por lo que utilizar Copilot también implicó revisar y aprender de las respuestas que proporcionaba.
